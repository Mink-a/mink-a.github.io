## Overview

A SaaS platform that organizers use to run events end-to-end — registration, check-in, session tracking, and post-event analytics — powered by a face-recognition pipeline that identifies attendees from a single camera frame.

## What I built

- End-to-end attendee identification flow: enrolment on registration, real-time match on check-in, fallback to manual lookup.
- Event dashboard for organizers: live attendance counts, session occupancy, and exportable reports.
- Frontend in React with a clean architecture for camera capture, low-latency match calls, and graceful fallbacks when matches are uncertain.
